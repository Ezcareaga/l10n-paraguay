<objective>
Enable GitHub Discussions and create the 10 custom labels that `release.yml` and
the issue forms depend on. These are outward-facing repo-state changes that touch
GitHub directly — they cannot be done via a local file and require the maintainer
to run the commands.

Purpose: Without Discussions enabled, the config.yml Q&A contact_link 404s; without
the labels created, release-notes categorization and issue-form auto-labeling
silently fail (RESEARCH Pitfall 1 + Pitfall 4 / D-02, D-03).

Output: GitHub repo with Discussions on (Q&A category) + 10 labels present. No
files changed in the repo. Optionally refine config.yml's Q&A URL to the
confirmed category slug (follow-up commit).
</objective>

  </read_first>
  <what-built>
    Plan 04-02 created `release.yml` with categories keyed on labels
    (`feat`, `fix`, `changed`, `refactor`, `chore`, `security`, `docs`,
    `skip-changelog`, `dependencies`, `github-actions`) that do NOT yet exist in
    the repo (only the 9 GitHub defaults exist). GitHub silently skips missing
    labels, so they must be created for categorization + auto-labeling to work.
  </what-built>
  <action>
    Maintainer runs the 10 commands from RESEARCH Pattern 7 (do NOT recreate the
    existing defaults `bug`, `enhancement`, `documentation`):
    ```
    gh label create "feat"           --description "New feature (feat: commit type)"          --color "0075ca"
    gh label create "fix"            --description "Bug fix (fix: commit type)"               --color "d73a4a"
    gh label create "changed"        --description "Changed or improved behavior"            --color "e4e669"
    gh label create "refactor"       --description "Code refactoring without behavior change" --color "fef2c0"
    gh label create "chore"          --description "Build, tooling, or maintenance task"      --color "cfd3d7"
    gh label create "security"       --description "Security fix or hardening"                --color "ee0701"
    gh label create "docs"           --description "Documentation-only change"               --color "0075ca"
    gh label create "skip-changelog" --description "Exclude from auto-generated release notes" --color "ffffff"
    gh label create "dependencies"   --description "Dependency updates"      --color "0366d6" --force
    gh label create "github-actions" --description "GitHub Actions updates"  --color "0366d6" --force
    ```
    All commands target `Ezcareaga/l10n-paraguay` (add `--repo Ezcareaga/l10n-paraguay`
    if not run from a clone of that repo).
  </action>
