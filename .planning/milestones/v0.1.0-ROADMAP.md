## Phase Details

### Phase 1: Bloque A — Foundation técnica (CI/CD + pre-commit)

**Goal**: Cualquier push o PR a este repo dispara automáticamente lint + tests y `main` está protegido contra merges sin checks verdes.
**Depends on**: Nothing (Fase 1 ya está cerrada en `main`; esta phase desbloquea el resto del milestone).
**Requirements**: CI-01, CI-02, CI-03, CI-04, CI-05, CI-06, CI-07, CI-08 (8 REQs)
**Complexity**: large (8 REQs, 3-4 días — la phase más cargada de infra de la milestone)
**Execution mode**: Directa sin plans GSD (pre-GSD-plans; PRs #3-#13 a `main`)
**Internal sequencing** (no se puede paralelizar dentro de la phase):

1. CI-01 (configurar `.pre-commit-config.yaml`)
2. CI-02 (commit baseline `chore: apply pre-commit fixes baseline` — 100+ cambios cosméticos absorbidos en UN commit)
3. CI-04 (activar `lint.yml` que corre el pre-commit ya estabilizado)
4. CI-03 + CI-05 + CI-06 en paralelo (test workflow, dependabot, commitlint son independientes entre sí)
5. CI-07 (branch protection) — necesita que los status checks ya existan en GitHub para poder marcarlos como required
6. CI-08 (PR de prueba `chore: ci sanity check`) — verificación final end-to-end

**Success Criteria verificados**:

1. `pre-commit run --all-files` corre limpio sobre todo el repo
2. Push directo a `main` rechazado por GitHub branch protection
3. PR de prueba dispara `lint.yml` + `test.yml`, ambos verdes antes de mergear
4. Dependabot configurado para Python deps + GitHub Actions versions (semanal)
5. Commit que viola Conventional Commits rechazado por commitlint Action

### Issues resueltos en el milestone

- **Digest drift `oca-gen-addon-readme`** (Windows backslash vs Linux): resuelto con `--keep-source-digest` en `.pre-commit-config.yaml` (PR #24)
- **commitlint footer trap**: referencia `#N` en body de commit activa commitlint; evitado en mensajes de commit
- **Content filter CoC**: Contributor Covenant generado vía `curl` directo — no vía subagent
- **Bandit 0 findings**: `addons/` pasó con 0 findings any severity (2228 LOC, confirmado gitleaks v8.30.1 + bandit 1.9.4)
- **Branch protection 6 contexts**: `gitleaks`, `bandit`, `dependency-review`, `pre-commit`, `test with Odoo`, `commitlint` — todos required en `main`
- **Ley 7593/2025 vs 6534/2020**: amendment A-01 — Ley 6534 aplica solo a datos crediticios (BCP); Ley 7593/2025 es la GDPR-style general; verificado verbatim vía Exa MCP
