Facturación electrónica SIFEN/e-Kuatia para Paraguay: generación del Código
de Control (CDC), construcción y firma XAdES del XML de Documento Electrónico
(DE), envío al web service DNIT, generación del KuDE (comprobante visual) y
gestión de eventos (cancelación, conformidad, etc.).

Implementa ``account.edi.format`` con código ``py_dnit_sifen`` sobre el
framework ``account_edi`` de Odoo 18.
